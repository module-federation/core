Divebell includes the Observability Plugin. Add `--mf` when opening a page with
Divebell, then run the following command to inspect Module Federation module
loading performance for the current page:

```bash
divebell mf module-perf --report --view timeline
```

[![Divebell Module Federation performance timeline](https://raw.githubusercontent.com/2heal1/divebell/main/assets/mf-module-perf-timeline.png)](https://github.com/2heal1/divebell#quick-start)

See the
[Divebell MF Extension documentation](https://github.com/2heal1/divebell/blob/main/packages/extensions/mf/README.md)
for more commands and usage details.
