Si usas el plugin `@module-federation/modern-js-v3`, la entrada asíncrona correspondiente se habilitará de forma predeterminada según el tipo de builder.

Sin embargo, si se trata del [modo build](https://modernjs.dev/en/guides/concept/entries.html#build-mode-entry), aún tendrás que configurar la entrada asíncrona manualmente.

A continuación, mostraremos cómo habilitar la entrada asíncrona.

Crea el archivo bootstrap.js y copia en él el contenido del archivo de entrada original:

```diff title="bootstrap.js"
+ import React from 'react';
+ import ReactDOM from 'react-dom';
+ import App from './App';
+ ReactDOM.render(<App />, document.getElementById('root'));
```

Modifica el contenido del archivo de entrada original para que haga referencia a bootstrap.js:

```diff title="index.js"
+ import('./bootstrap');
- import React from 'react';
- import ReactDOM from 'react-dom';
- import App from './App';
- ReactDOM.render(<App />, document.getElementById('root'));
```
