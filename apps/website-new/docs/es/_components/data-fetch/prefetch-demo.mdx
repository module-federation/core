### Escenario 1: Hacer prefetch solo de los datos

Cuando un usuario pasa el cursor sobre un enlace que lleva a la página de la tienda, podemos hacer prefetch de los datos que necesita esa página.

```ts
import { getInstance } from '@module-federation/enhanced/runtime';

const instance = getInstance();

const handleMouseEnter = () => {
  instance.prefetch({
    id: 'shop/Button',
    dataFetchParams: { productId: '12345' },
  });
};
```

### Escenario 2: Hacer prefetch de los datos y precargar los recursos del componente

Para optimizar aún más, podemos descargar los archivos JS y CSS del componente al mismo tiempo que hacemos prefetch de los datos.

```ts
import { getInstance } from '@module-federation/enhanced/runtime';

const instance = getInstance();

const handleMouseEnter = () => {
  instance.prefetch({
    id: 'shop/Button',
    dataFetchParams: { productId: '12345' },
    preloadComponentResource: true,
  });
};
```
