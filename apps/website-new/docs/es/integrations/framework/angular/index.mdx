# Descripción general de la integración con Angular

Al integrar Module Federation en una aplicación Angular, elige la guía en función de la configuración de build de tu proyecto.

| Tipo de proyecto | Lectura recomendada |
| --- | --- |
| Proyecto de Angular CLI | [Configuración de Angular CLI](/integrations/framework/angular/angular-cli.html) |
| Workspace de Nx | [Usar Nx CLI para Angular](/integrations/framework/angular/using-nx-for-angular.html) |
| Ejemplo completo de micro-frontend | [Angular MFE](/integrations/framework/angular/angular-mfe.html) |
| Escenario SSR | [Angular SSR](/integrations/framework/angular/mf-ssr-angular.html) |
| Escenario con Service Worker | [Service Workers con Module Federation](/integrations/framework/angular/service-workers-mf.html) |

Las integraciones con Angular suelen depender de Angular CLI, de un builder personalizado de Webpack o de Nx. Antes de elegir una guía, confirma tu configuración de build actual y si necesitas SSR.

Si solo necesitas los conceptos de configuración comunes de Module Federation, consulta [Configuración](/configure/index.html) para `name`, `remotes`, `exposes` y `shared`.
