# Presets

## Shared

Por defecto, ciertos módulos internos de Next.js se comparten automáticamente para optimizar tu aplicación.
Ten en cuenta que compartir manualmente estos módulos internos puede provocar errores, ya que se gestionan por ti.

- `next/dynamic`
- `next/head`
- `next/link`
- `next/router`
- `next/script`
- `react`
- `react/`
- `react-dom`
- `react-dom/`
- `styled-jsx`
- `styled-jsx/style`

## Exponer páginas

Puedes exponer automáticamente todas las páginas mediante el plugin

```javascript
new NextFederationPlugin({
  name: 'remoteApp',
  filename: '',
  remotes: {},
  exposes: {},
  shared: {},
  extraOptions: {
    exposePages: true
  },
});
```

Así, las páginas quedarán disponibles para importarlas de esta forma:

- `import Page from 'remoteApp/pages/index'`
- `import Page from 'remoteApp/pages/shop/product'`

## Opciones de build
### Public Path

Public Path se establece en "auto"

`config.output.publicPath: "auto"`

### Target

El target de salida de Webpack cambia de `node` a `async-node`

`config.target = "async-node"`
