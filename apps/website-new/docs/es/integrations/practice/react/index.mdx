# Práctica con React

Las aplicaciones React no usan un único plugin de Module Federation específico para React. Elige primero la integración según el bundler que use tu proyecto y, después, consulta estas guías de escenarios con React.

| Tipo de proyecto | Siguiente lectura |
| --- | --- |
| Rsbuild | [Rsbuild](/integrations/build-tool/rsbuild.html) |
| Rslib | [Rslib](/integrations/build-tool/rslib.html) |
| Rspack | [Rspack](/integrations/bundler/rspack.html) |
| Webpack | [Webpack](/integrations/bundler/webpack.html) |
| Vite | [Vite](/integrations/build-tool/vite.html) |
| Carga de remotes en runtime | [Instalación del runtime](/guide/runtime/index.html#installation) |

Si necesitas cargar componentes React remotos, continúa con [Bridge](/guide/bridge/overview.html). Si los componentes remotos necesitan obtención de datos, caché de datos o prefetch, continúa con [Gestión de datos](/guide/data/data-fetch.html).
