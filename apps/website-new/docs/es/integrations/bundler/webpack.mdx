# Webpack

- Permite construir módulos que cumplen la especificación de carga de {props.brandName || props.name || 'Module Federation'}.
- Permite consumir módulos de la especificación {props.brandName || props.name || 'Module Federation'} mediante alias.
- Permite definir la configuración de dependencias compartidas de los módulos. Si el entorno host en el que se carga el módulo ya tiene la dependencia correspondiente, no se volverá a cargar.
- Cuando un módulo tiene tipos remotos, los tipos del módulo remoto se descargan automáticamente para su consumo.
- Recarga en caliente (hot reload) al consumir módulos remotos.

### Instalación

Puedes instalar el plugin con el siguiente comando:

import InstallKit from '@docs/_snippets/install-kit';

<InstallKit
  pkgName={props.enhancedPackage || props.pkgName}
/>

### Crear {props.configName || 'module-federation.config.js'}

Crea un archivo {props.configName || 'module-federation.config.js'} con el siguiente contenido:

import CreateConfig from '@docs/_snippets/webpack/create-config';

{props.createConfig || <CreateConfig />}

### Registrar el plugin

En `Webpack`, puedes añadir el plugin mediante la opción `plugins` del archivo de configuración `webpack.config.js`:

import RegisterPlugin from '@docs/_snippets/webpack/register-plugin';

{props.registerPlugin || <RegisterPlugin />}
