# Paquetes npm

Este documento recoge la información de todos los paquetes npm que mantiene el equipo de Module Federation.

## @module-federation/enhanced

![](https://img.shields.io/npm/v/@module-federation/enhanced?style=flat-square&colorA=564341&colorB=EDED91)

El paquete principal de Module Federation, que funciona como plugin de build para Webpack, plugin de build para Rspack y dependencia de entrada del runtime.

- [npm](https://npmjs.com/package/@module-federation/enhanced)
- [Código fuente](https://github.com/module-federation/core/tree/main/packages/enhanced)
- [Documentación del runtime](/guide/runtime/index.html)
- [Plugin de build para Rspack](/integrations/bundler/rspack.html)
- [Plugin de build para Webpack](/integrations/bundler/webpack.html)

## @module-federation/runtime

![](https://img.shields.io/npm/v/@module-federation/runtime?style=flat-square&colorA=564341&colorB=EDED91)

El paquete de runtime de Module Federation. Normalmente se usa junto con @module-federation/enhanced para aprovechar las capacidades del runtime, y se puede instalar por separado si no necesitas ninguna herramienta de build.

- [npm](https://npmjs.com/package/@module-federation/runtime)
- [Código fuente](https://github.com/module-federation/core/tree/main/packages/runtime)
- [Documentación](/guide/runtime/index.html)

## @module-federation/rspack

![](https://img.shields.io/npm/v/@module-federation/rspack?style=flat-square&colorA=564341&colorB=EDED91)

El plugin de build de Module Federation para Rspack. Normalmente se usa junto con @module-federation/enhanced y no se puede usar de forma independiente sin la API de runtime.

- [npm](https://npmjs.com/package/@module-federation/rspack)
- [Código fuente](https://github.com/module-federation/core/tree/main/packages/rspack)
- [Documentación](/integrations/bundler/rspack.html)
