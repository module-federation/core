# Precarga de datos

La función `prefetch` carga los recursos y datos de un módulo remoto antes de que el usuario lo necesite. Así puedes reducir la espera al abrir una página o usar un componente.

import React from 'react';
import PrefetchTip from '@docs/es/_components/data-fetch/prefetch-tip';

{props.prefetchTip || React.createElement(PrefetchTip)}

## Cuándo usarla

`prefetch` es la opción ideal cuando quieres precargar el JavaScript, el CSS o los datos asociados a un componente sin renderizarlo de inmediato. Por ejemplo, puedes activar `prefetch` cuando el usuario pasa el cursor sobre un enlace o un botón, de modo que, cuando realmente haga clic, el componente se renderice más rápido.

## API

```typescript
interface ModuleFederation {
  prefetch(options: {
    id: string;
    dataFetchParams?: Record<string, any>;
    preloadComponentResource?: boolean;
  }): void;
}
```

### Parámetros

```ts
type PrefetchOptions = {
  // Unique identifier for the remote module, in the format '<remoteName>/<exposedModule>', e.g. 'shop/Button'.
  id: string;

  // If the remote component has a data fetch function, this object will be passed to it.
  dataFetchParams?: Record<string, any>;

  // Whether to preload the component's resources, including JavaScript chunks and associated CSS files. Defaults to false.
  preloadComponentResource?: boolean;
};
```

## Ejemplos de uso

Supongamos que tenemos una aplicación remota `shop` que expone un componente `Button`, y que este componente tiene asociada una función de obtención de datos.
