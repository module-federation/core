# treeShakingSharedExcludePlugins

Configura los nombres de los plugins que se excluyen durante el proceso de tree shaking/fallback de las dependencias compartidas. Estos plugins se ignoran y no participan en el proceso de tree shaking/fallback de las dependencias compartidas.

- Tipo: `string[]`
- Obligatorio: No
- Valor por defecto: `['HtmlWebpackPlugin','HtmlRspackPlugin']`
