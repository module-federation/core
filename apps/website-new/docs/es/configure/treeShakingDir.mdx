# treeShakingDir

Cuando la [funcionalidad de Tree Shaking de dependencias shared](/guide/advanced/shared-tree-shaking.html) está habilitada, {props.brandName || props.name || 'Module Federation'} extrae los exports de los módulos shared que no se usan. Esta opción especifica el directorio de salida para esos assets de fallback.

- Tipo: `string`
- Obligatorio: No
- Valor por defecto: `undefined`
