一次性排查真实页面时，先在 Agent 所在机器手动安装 MF Extension。安装后，
Divebell 可以在导航前启用 Extension 提供的 MF 诊断，不需要先给应用接入
观测插件：

```bash
npm install --global @divebell/cli
divebell extensions add @divebell/extension-mf
divebell setup
divebell open "https://example.com" --mf
```

AI Coding Agent 应先读取 `divebell skill` 返回的 CLI Skill，再读取
`divebell mf --skill` 返回的 Extension Skill。随后可以查看 MF 当前状态、
加载链路、Shared 版本选择、Bridge 操作或模块性能。例如：

```bash
divebell mf module-perf --report --view timeline
```
