# 动态远程模块

```js
import { loadRemote, updateRemotes } from '@module-federation/runtime';

// The build plugin initializes the host instance. Add or replace a remote,
// then wait for its previous cache cleanup before loading the new entry.
await updateRemotes([
  { name: 'home', entry: 'http://example.com/remoteEntry.js' },
]);
await loadRemote('home/exposedModule');
```
