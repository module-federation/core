# Überblick zur Angular-Integration {#angular-integration-overview}

Wenn du Module Federation in eine Angular-Anwendung integrierst, wähle die Anleitung passend zum Build-Setup deines Projekts.

| Projekttyp | Weiterführende Anleitung |
| --- | --- |
| Angular-CLI-Projekt | [Angular CLI einrichten](/integrations/framework/angular/angular-cli.html) |
| Nx-Workspace | [Nx CLI für Angular verwenden](/integrations/framework/angular/using-nx-for-angular.html) |
| Vollständiges Microfrontend-Beispiel | [Angular MFE](/integrations/framework/angular/angular-mfe.html) |
| SSR-Szenario | [Angular SSR](/integrations/framework/angular/mf-ssr-angular.html) |
| Service-Worker-Szenario | [Service Worker mit Module Federation](/integrations/framework/angular/service-workers-mf.html) |

Angular-Integrationen verwenden üblicherweise Angular CLI, einen angepassten Webpack-Builder oder Nx. Prüfe dein aktuelles Build-Setup und ob du SSR benötigst, bevor du eine Anleitung auswählst.

Wenn du nur die allgemeinen Module-Federation-Konfigurationskonzepte brauchst, findest du unter [Konfiguration](/configure/index.html) Informationen zu `name`, `remotes`, `exposes` und `shared`.
