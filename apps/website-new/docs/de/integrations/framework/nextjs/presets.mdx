# Presets {#presets}

## Shared {#shared}

Bestimmte Next.js-interne Pakete werden standardmäßig automatisch geteilt, um deine Anwendung zu optimieren.
Wenn du sie zusätzlich manuell teilst, kann das Fehler verursachen, da das Plugin sie bereits verwaltet.

- `next/dynamic`
- `next/head`
- `next/link`
- `next/router`
- `next/script`
- `react`
- `react/`
- `react-dom`
- `react-dom/`
- `styled-jsx`
- `styled-jsx/style`

## Seiten bereitstellen {#expose-pages}

Du kannst mit dem Plugin automatisch alle Seiten bereitstellen:

```javascript
new NextFederationPlugin({
  name: 'remoteApp',
  filename: '',
  remotes: {},
  exposes: {},
  shared: {},
  extraOptions: {
    exposePages: true
  },
});
```

Die Seiten lassen sich anschließend beispielsweise so importieren:

- `import Page from 'remoteApp/pages/index'`
- `import Page from 'remoteApp/pages/shop/product'`

## Build-Optionen {#build-options}
### Public Path {#public-path}

Public Path wird auf "auto" gesetzt.

`config.output.publicPath: "auto"`

### Target {#target}

Das Webpack-Ausgabeziel wird von `node` auf `async-node` gesetzt.

`config.target = "async-node"`
