# Webpack {#webpack}

- Erstellt Module gemäß der Ladespezifikation von {props.brandName || props.name || 'Module Federation'}.
- Lädt Module gemäß der Spezifikation von {props.brandName || props.name || 'Module Federation'} über Aliase.
- Konfiguriert Shared-Abhängigkeiten: Ist die passende Abhängigkeit bereits im Host verfügbar, wird sie nicht erneut geladen.
- Lädt Remote-Typen automatisch herunter und verwendet sie, sofern das Modul welche bereitstellt.
- Unterstützt Hot Reloading für geladene Remote-Module.

{props.tip}
