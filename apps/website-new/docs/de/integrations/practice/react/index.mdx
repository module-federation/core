# React in der Praxis {#react-practice}

Für React-Anwendungen gibt es kein einzelnes festes React-spezifisches Module-Federation-Plugin. Wähle zuerst die Integration passend zum Bundler deines Projekts und nutze anschließend diese Anleitungen für konkrete React-Anwendungsfälle.

| Projekttyp | Weiterführende Anleitung |
| --- | --- |
| Rsbuild | [Rsbuild](/integrations/build-tool/rsbuild.html) |
| Rslib | [Rslib](/integrations/build-tool/rslib.html) |
| Rspack | [Rspack](/integrations/bundler/rspack.html) |
| Webpack | [Webpack](/integrations/bundler/webpack.html) |
| Vite | [Vite](/integrations/build-tool/vite.html) |
| Remotes zur Laufzeit laden | [Runtime installieren](/guide/runtime/index.html#installation) |

Wenn du React-Komponenten aus Remotes laden möchtest, lies unter [Bridge](/guide/bridge/overview.html) weiter. Benötigen die Remote-Komponenten Datenabruf, Daten-Caching oder Prefetch, findest du weitere Informationen unter [Datenverwaltung](/guide/data/data-fetch.html).
