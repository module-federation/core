# runtimePlugins

- Typ: `string[] | Array<[string, Record<string, unknown>]>`
- Erforderlich: Nein
- Standardwert: `undefined`

Mit `runtimePlugins` ergänzt du Plugins, die zur Laufzeit benötigt werden. Der Wert kann folgende Formen haben:
- Ein String mit dem Pfad zum jeweiligen Plugin (absoluter oder relativer Pfad oder Paketname)
- Ein Array, dessen Elemente Strings oder Tupel aus [Pfad als String, Optionen als Objekt] sind

Eine Anleitung zur Auswahl von Hooks und zur Entwicklung von Plugins findest du unter [Runtime-Plugins](/guide/runtime/runtime-plugins.html). Die vollständige Hook-Referenz steht unter [Runtime-Hooks](/guide/runtime/runtime-hooks.html). Weiterführende Details zur Plugin-Entwicklung findest du unter [Plugin-System](/plugin/dev/index.html).

Die konfigurierten Runtime-Plugins werden während des Builds automatisch eingefügt und eingebunden.

**Grundlegende Verwendung:**
Erstelle eine Datei für dein Runtime-Plugin, beispielsweise `custom-runtime-plugin.ts`:

```ts title="custom-runtime-plugin.ts"
import { ModuleFederationRuntimePlugin } from '@module-federation/enhanced/runtime';

export default function (): ModuleFederationRuntimePlugin {
  return {
    name: 'custom-plugin-build',
    beforeInit(args) {
      console.log('[build time inject] beforeInit: ', args);
      return args;
    },
    beforeLoadShare(args) {
      console.log('[build time inject] beforeLoadShare: ', args);
      return args;
    },
  };
}
```

Binde das Plugin anschließend in deine Build-Konfiguration ein:

```ts title="rspack.config.ts"
const path = require('path');
module.exports = {
  plugins: [
    new ModuleFederationPlugin({
      name: 'host',
      remotes: {
        'manifest-provider':
          'manifest_provider@http://localhost:3011/mf-manifest.json',
      },
      runtimePlugins: [path.resolve(__dirname, './custom-runtime-plugin.ts')],
    }),
  ],
};
```

**Mit Optionen:**
Über das Tupelformat kannst du Runtime-Plugins auch Optionen übergeben:

```ts title="rspack.config.ts"
const path = require('path');
module.exports = {
  plugins: [
    new ModuleFederationPlugin({
      name: 'host',
      remotes: {
        'manifest-provider':
          'manifest_provider@http://localhost:3011/mf-manifest.json',
      },
      runtimePlugins: [
        path.resolve(__dirname, './custom-runtime-plugin.ts'),
        [
          path.resolve(__dirname, './another-plugin.ts'),
          {
            debug: true,
            timeout: 5000,
            customConfig: 'value'
          }
        ]
      ],
    }),
  ],
};
```

Das Plugin kann dann auf diese Optionen zugreifen:

```ts title="another-plugin.ts"
import { ModuleFederationRuntimePlugin } from '@module-federation/enhanced/runtime';

export default function (options: any): ModuleFederationRuntimePlugin {
  console.log('Plugin options:', options);

  return {
    name: 'another-plugin',
    beforeInit(args) {
      if (options.debug) {
        console.log('[debug] beforeInit: ', args);
      }
      return args;
    },
  };
}
```
