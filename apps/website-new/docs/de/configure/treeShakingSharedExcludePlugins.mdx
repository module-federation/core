# treeShakingSharedExcludePlugins

Legt die Plugin-Namen fest, die beim Tree Shaking bzw. beim Erzeugen von Fallbacks für Shared-Abhängigkeiten ausgeschlossen werden. Diese Plugins werden ignoriert und nehmen an diesem Prozess nicht teil.

- Typ: `string[]`
- Erforderlich: Nein
- Standardwert: `['HtmlWebpackPlugin','HtmlRspackPlugin']`
