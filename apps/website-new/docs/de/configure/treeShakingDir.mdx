# treeShakingDir

Wenn [Tree Shaking für Shared-Abhängigkeiten](/guide/advanced/shared-tree-shaking.html) aktiviert ist, extrahiert {props.brandName || props.name || 'Module Federation'} die Exports nicht verwendeter Shared-Module. Diese Option legt das Ausgabeverzeichnis für diese Fallback-Assets fest.

- Typ: `string`
- Erforderlich: Nein
- Standardwert: `undefined`
