# NPM-Pakete {#npm-packages}

Diese Seite stellt die npm-Pakete vor, die das Module-Federation-Team pflegt.

## @module-federation/enhanced {#module-federationenhanced}

![](https://img.shields.io/npm/v/@module-federation/enhanced?style=flat-square&colorA=564341&colorB=EDED91)

Das Kernpaket von Module Federation. Es dient als Webpack-Build-Plugin, Rspack-Build-Plugin und Abhängigkeit für den Einstieg in die Runtime.

- [npm](https://npmjs.com/package/@module-federation/enhanced)
- [Quellcode](https://github.com/module-federation/core/tree/main/packages/enhanced)
- [Runtime-Dokumentation](/guide/runtime/index.html)
- [Rspack-Build-Plugin](/integrations/bundler/rspack.html)
- [Webpack-Build-Plugin](/integrations/bundler/webpack.html)

## @module-federation/runtime {#module-federationruntime}

![](https://img.shields.io/npm/v/@module-federation/runtime?style=flat-square&colorA=564341&colorB=EDED91)

Das Runtime-Paket von Module Federation. Es wird üblicherweise zusammen mit @module-federation/enhanced verwendet, um Runtime-Funktionen zu nutzen. Wenn du kein Build-Werkzeug benötigst, kannst du es auch separat installieren.

- [npm](https://npmjs.com/package/@module-federation/runtime)
- [Quellcode](https://github.com/module-federation/core/tree/main/packages/runtime)
- [Dokumentation](/guide/runtime/index.html)

![](https://img.shields.io/npm/v/@module-federation/rspack?style=flat-square&colorA=564341&colorB=EDED91)
