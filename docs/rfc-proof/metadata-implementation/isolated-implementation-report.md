## Implemented source/API

The runtime-core root and `/kernel` export `RUNTIME_IMAGE`, readonly `RuntimeImageDescriptorV1`, `parseRuntimeImage`, `attachRuntimeImage`, `readRuntimeImage`, and `assertRuntimeImageCompatible`. The existing runtime/core barrel exposes the same helpers. Runtime root gains additive `UserOptions.runtimeImage` through its existing option types; it does not gratuitously re-export the helpers. `RemoteEntryInitOptions.runtimeImage` is additive, supporting explicit container-init requests. Parser accepts unknown, permits only undefined absence, rejects malformed structure and unsupported contract before comparisons, snapshots fields once, copies all three capability arrays, validates the copied snapshot, and freezes arrays plus record. Attach/read retain independent immutable copies; no caller metadata references are retained.

The supported v1 comparisons remain unchanged: provider available∪required must cover consumer available∪required; next forbidden must be absent from the provider union; ABI compatibilityId, target, and entryLoadingIdentity must match. Both absent is **unchecked**. Exactly one absent warns and allows **unchecked** reuse. Malformed metadata always rejects. Shape-only first admission does not self-compare required/forbidden overlap. Internal duplicate image claims use scalar plus set equivalence; array order and duplicates do not change v1 meaning. Distinct explicit options/plugin claims are checked in both directions before any constructor state, then retain the validated owned claim.

Core and generic runtime normalize the existing image symbol association on owned injector plugins before construction/reuse and require all four metadata functions before metadata-aware calls. Real premetadata 7aca helpers remain optional when both tags are absent; no fabricated/no-op namespace functions are added. Known images, configured plugin claims, family registration, and published old-core minimum failures are checked before handlers/plugins. Hook-returned options and plugin associations are reparsed before remote/shared registration. A known admitted image is retained if a hook removes both tags; incompatible changed images reject. An initially absent image may be introduced by a valid hook.

The injector parses/copies factory config before construction. Tagged publication uses the existing `init` lifecycle after all `beforeInit` metadata checks, instead of writing provider slots in `beforeInit`. Tagged SharedHandler constructors defer their initial global share-map publication to existing `registerShared`, after admission. Untagged legacy publication/share-map timing is retained. The actual tagged injector followed by a null-returning `beforeInit` hook rejects without either provider-slot reference, registry reference/instance contents, or SHARE state changing. Arbitrary user hooks can have their own side effects; this is not generic rollback. Untagged constructors preserve historical hook side effects.

Rspack default/global external root admission runs before root/kernel dereference, through the existing slots `_FEDERATION_RUNTIME_CORE` and `_FEDERATION_RUNTIME_CORE_FROM`. It emits the actual self-contained parser and invokes the published actual comparator. Unknown provider info is checked as a record before reading fields; structural errors precede the minimum API diagnostic. Metadata requires Global and all four helper callables before namespace access; legacy bootstrap still requires honest existing kernel/root callables and registry shape. Missing old helpers with supplied metadata give `RuntimeImageMinimumContract`, including real old cores. Root/kernel export projection uses genuine optional metadata values; unsupported leaves retain named compilation failure.

For non-global transports, explicit compiler metadata rejects with `RuntimeImageTransportBoundary`. An unprofiled consumer encountering a tagged provider also rejects at the exact root adapter before namespace property reads. Untagged native CommonJS transport keeps `_FEDERATION_RUNTIME_CORE` as the external package target and returns its complete actual namespace/default, including an extra export. Only default/global and CommonJS execution are proved here; other native external transport types retain their legacy target via the same exact-root adapter but have no separate execution claim.

SDK adds Rspack-only `experiments.runtimeImage: {compatibilityId, entryLoadingIdentity}`. These are explicit caller ABI/evaluator guarantees, not package-name/version observations. Derivation requires externalRuntime/provideExternalRuntime, explicit optimization.target web/node, the owned built-in implementation, and known plugin needs. Opaque custom implementation/plugins, composed-only profiles, missing target, malformed flags, post-DTS opaque plugins, and user DefinePlugin capability/target overrides reject precisely. React bridge routing does not inject runtime plugins and is not blanket-rejected. Compiler flags/target are captured once; emitted DefinePlugin definitions use the admitted image rather than rereading mutable accessors. Minor retained capabilities exactly match legacy defines: shared unless disabled; remote unless disabled; snapshot only if remote and snapshot are enabled; platform iff shared or remote exists. Required and available include ALL retained families under v1 unions. Consumer profiles are the expected image, never proof of provider availability; provider metadata is validated separately. Metadata plugin factories are whole-body base64 data modules importing the real injector, avoiding runtime-plugin parameter/version assumptions. Enhanced rejects this Rspack-only profile before its defines/container setup.

WBR carries the actual same-instance image into container `initOptions`, before explicit remoteEntryInitOptions overrides. It avoids accidental missing-metadata admission internally and preserves explicit incompatible override rejection. Existing mocks gained their real required `options` shape, without weakening assertions. A changeset covers seven affected public packages.
